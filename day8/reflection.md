# Course Reflection

The most difficult concept in this course was understanding how technical components work together in a system, especially how architecture decisions affect performance, reliability and data consistency. At first, concepts such as load balancing, caching, database relationships and scaling seemed like separate topics. I overcame this by applying them to practical examples and breaking each design into smaller steps: identifying requirements, estimating traffic, designing the API and data model, drawing the architecture, and explaining the trade-offs. Building the QuickNotes capstone helped me connect these ideas. I learned that a working interface is only one part of an application; the API, data structure, reliability and user experience must also fit together.

Based on my review of the QuickNotes capstone, the area I would improve is the connection between the frontend demonstration and the proposed backend architecture. The application demonstrated note operations using an API client, while the design documents described a larger system with data relationships and scaling considerations. A useful improvement would be to connect the demonstration to a persistent backend and database, then show how requests, validation and errors move through the system. I would also strengthen the live demonstration by showing network requests and explaining how the documented API endpoints support each feature. This is constructive feedback from reviewing the project, rather than a claim that a particular audience member gave me that comment.

Next, I want to learn backend development more deeply, especially building REST APIs, working with relational databases, authentication, automated testing and deployment. I also want to practise system design with realistic traffic estimates and failure scenarios. My goal is to move beyond building features that work locally and become confident designing, testing and explaining reliable applications that can serve real users. I aim to build dependable systems as user demand grows.
